기준 장비와 배선

헤드폰 EAGLE에서 U$1은 DWM1000, UWB 호스트는 ATmega328P다. MOSI2·MISO2·SCK2와 DWM1000_CS, IRQ, RST, WAKEUP, EXTON을 대조한다. VDDAON과 두 VDD3V3 패드는 VCC_LPS에 연결된다. LPS 보드 부품표의 U$3도 DWM1000이다.

DWM1000 설계 변경 순서

  1. 현행 설계 동결 → 원본 EAGLE·BOM과 동작 보드의 버전, 사용 가능한 펌웨어·설정·로그를 묶는다. 실물 전압, 이어컵 내부 치수와 안테나 위치를 측정한다.
  2. 변경 범위 확정 → 핀 호환 교체, 별도 MCU를 가진 캐리어 추가, RF 칩 직접 설계 중 해당 방식을 선택한다. 호스트, 안테나, 전원, 게이트웨이와 앱의 변경 목록을 작성한다.
  3. 회로·기구 설계 → 부품별 전원 한계와 피크 전류, 패드·비움 영역, 디버그 접근·조립 높이를 점검한다. 새 부품표, 회로도, PCB, 기구 간섭 검토본을 남긴다.
  4. 펌웨어·연동 → 호스트 드라이버 또는 모듈 명령 규약, 기동·복구, 교정값 저장 방식을 결정한다. 기존 앵커용 레거시 설정과 모바일 보안 세션은 별도 시험 구성으로 관리한다.
  5. 시제품 및 회귀 → 예비 보드 한 대에서 먼저 검증하고 같은 버전으로 조립·착용 시험을 반복한다. 오디오 재생, 재부팅, 서버 연속 출력까지 통과한 버전의 BOM·펌웨어·교정값·시험 로그를 함께 보관한다. 실패 시 보관한 기준 장비로 시험 환경부터 재확인한다.

방향 센서 조립 검수

  1. 각 헤드폰 BOM에 UWB 부품과 머리 방향 IMU를 각각 기록한다. U4 재사용, 신규 BMI270·BMI323 실장, 또는 확인된 JP11 외장 장치 중 실제 선택한 경로를 명시한다. 새 IMU는 EAGLE 패드와 전원, 호스트 드라이버, 이어컵의 고정 방향을 확인한다.
  2. 조립품에서 센서 ID와 시간표시가 있는 3축 가속도·3축 각속도 또는 외장 장치의 자세 패킷을 확보한다. 외장 경로는 JP11 전압·핀·UART 형식을 확인한다. 움직임 감지 이벤트만 수신하면 방향 기능은 미검증으로 기록한다.
  3. 정면 기준에서 축을 보정하고 수평으로 고개만 90° 회전시킨다. 태블릿은 고정한 상태에서 머리 회전각과 복귀 오차, 한 체험 회차 동안의 방위 드리프트를 기록한다. 재착용 후 반복해 센서 고정과 보정의 재현성을 판정한다.

신규 모듈 측정과 판정

  1. 기준선 확보. 정상 DWM1000 한 세트를 대조군으로 보관한다. 보드 버전·펌웨어·채널·PHY·안테나 방향·앵커 좌표를 기록하고, 기존 헤드폰으로 기준점과 보행 경로의 로그를 얻는다.
  2. 벤치 시험. 전원 전류 제한은 부품 사양에 맞춘다. 전압·기동 파형, 장치 식별, 양방향 패킷, 리셋 및 슬립 복귀를 순서대로 확인한다. 실패 시 최초로 어긋난 신호나 패킷과 펌웨어 버전을 남긴다.
  3. 거리·위치 시험. 줄자로 확인한 가까운·중간·먼 지점을 정하고 후보마다 같은 위치와 횟수로 반복한다. 거리 오차와 서버 좌표 오차를 구분한다. 앵커 위치와 측정 좌표계를 함께 보관한다.
  4. 착용·전력 시험. 이어컵 개방, 조립, 착용, 고개 회전, 인체 가림 순으로 반복한다. 오디오 재생 중 측정과 절전·측정·재연결 전류를 기록한다. 기준 헤드폰과 같은 경로로 비교한다.
  5. 스마트폰 태그 시험. 목표 iOS·Android 각각에서 한 앵커와의 거리, 복수 앵커의 동일 단말 식별, 서버 좌표 수신을 순서대로 확인한다. 화면 잠금, 앱 재개, 연결 단절 후 동일 시험을 반복한다. 상대 거리만 확보되면 서버 측위는 미검증으로 기록한다.

두 장치의 방향 분리 시험

  1. 전시장 기준 표식에 두 장치를 정렬하고 동일 관람객의 tablet_id와 headset_id를 연결한다. 두 자세의 측정 시각을 같은 시간축에 맞추고 좌표계, 품질, UWB 위치를 함께 기록한다.
  2. 태블릿을 고정하고 고개만 좌우로 90° 돌린다. 반대로 머리를 고정하고 태블릿만 돌린다. 움직인 장치의 각도 오차·지연과 정지 장치에 생긴 각도 변화를 각각 기록한다.
  3. 두 장치를 서로 반대로 돌리고 알려진 정면으로 복귀한다. 한 회차 동안 머리 방위 드리프트를 측정하고, 헤드폰 재착용 및 태블릿 AR 추적 재개 후 좌표 정렬을 반복한다. 콘텐츠 허용 오차와 지연 기준으로 판정한다.

AoA 수신 방향 시험

각도를 출력할 수신기를 헤드폰 또는 앵커 중 하나로 지정한다. 수신기의 정면을 0°로 정하고 송신기를 알려진 거리와 방위각에 놓는다. 원시 위상차를 제공하면 함께 저장하고, 각도 출력 좌표계·유효 범위·보정값을 기록한다. 기준 각도와의 절대오차, 95백분위 오차, 유효 각도 출력률을 비교한다. 이어컵 조립 전후와 착용 중 고개 회전·인체 가림 조건을 반복한다. 폰 화면에서만 표시된 각도는 폰 측 결과로 기록한다.

공유 앵커에서 여러 쌍 검증

  1. 목표 동시 관람객 수, 단말별 갱신 주기와 최대 지연, 폰 자체의 UWB 위치 필요 여부를 먼저 기록한다. HP1+SP1 및 HP2+SP2를 등록하고 같은 앵커망에 연결한다. iOS·Android 혼합 구성에서 펌웨어 모드가 동시에 유지되는지 확인한다.
  2. 한 명씩, 두 명 동시, 목표 최대 인원 순으로 입장시킨다. 두 쌍이 교차하고 서로 가까워져도 각 화면과 서버 로그에 등록된 쌍의 위치와 두 자세만 연결되는지 대조한다.
  3. 폰 잠금·앱 재개, 헤드폰 전원 재인가, 반납 후 기기 재배정을 반복한다. 이전 회차 데이터 재사용·다른 쌍으로의 오배정은 0건이어야 한다. 단말별 유효 갱신률, 95백분위 지연, 연속 누락 시간과 재연결 시간을 기록해 사전 합의 기준과 비교한다.

시험 기록과 채택 기준

각 실행에 시험 ID, 후보·보드·펌웨어 버전, 폰 기종·OS, 앵커 ID·좌표, 기준점, 착용 조건, 반복 수, 원시 로그 위치를 남긴다. 결과는 거리 절대오차와 위치 오차의 중앙값·95백분위, 유효 좌표 갱신 간격, 누락률, 재접속 시간, 평균·피크 전류로 정리한다. 누락률의 분모는 설정한 예정 갱신 수로 통일한다.

시험 전에 전시 콘텐츠가 허용하는 위치 오차·최대 갱신 간격·운영 시간과 기구 여유를 정한다. 후보별 결과를 기준 장비 및 목표값과 대조해 통과·실패·미검증으로 표시한다. 목표값 없이 측정한 항목은 비교값으로 남기고 채택을 확정하지 않는다.
